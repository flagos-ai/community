# FlagOS 2.2 FEP Delivery and Validation

Updated: 2026-09-24

The active 2.2 scope contains 23 FEPs. FEP-0084 was already deferred by its
owner and is listed separately. Source revisions follow the module branches
in the [RC2 manifest](../release/2.2/release-2.2-rc2.yaml) at community
revision `a32392c`; each FEP records branch and tag revisions separately.

Lifecycle status follows the [FEP rules](README.md#fep-lifecycle).
`Implemented` means the FEP's acceptance scope is met. `Implementable` can
contain substantial completed code and testing with specific acceptance
items still open. `Provisional` is reserved for unresolved design or public
delivery scope. Passing feature tests retain their original revisions;
missing RC2-head checks do not erase earlier validation.
