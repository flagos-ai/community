# FlagOS 2.2 FEP Status at RC2

Updated: 2026-09-24

The 24 FEPs below include the feature already deferred from 2.2. Source
references use the module branches in the [RC2 manifest](../release/2.2/release-2.2-rc2.yaml)
at community revision `a32392c`. Each FEP records the inspected branch commit
and the manifest tag commit; they can differ. Code inclusion is checked from
the branch contents, including backports, rather than PR merge state alone.

Status follows the [FEP lifecycle](README.md#fep-lifecycle). `Implementable`
means the design and test plan are ready; it does not mean release acceptance
has passed. Recorded hardware results retain their original test revisions
and dates. This update adds no new hardware test results.

## Release Dependencies

- FlagTree CPU, FlagQuantum and verl-hardware-plugin have no module RC2
  branch or entry in the inspected release manifest. Their FEPs identify the
  available source and remaining delivery requirements.
- FlagPrism is an external FlagTree build dependency without a commit pin in
  the RC2 dependency registry. Its actual build revision must be recorded.
- Open acceptance items do not independently decide release blocking status;
  that decision belongs to release review.
